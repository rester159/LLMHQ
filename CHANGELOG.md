# Changelog

## 0.1.0

- Added local Fastify LLM gateway.
- Added OpenAI-style chat completions endpoint.
- Added stateful file-backed conversations by `project_id + conversation_key`.
- Added Claude CLI worker and model aliases for Haiku, Sonnet, and Opus.
- Added Codex CLI worker and `codex-gpt-5.5` alias.
- Added experimental ChatGPT browser image generation worker.
- Added local generated asset storage.
- Added Docker Compose setup for private same-server deployment.
- Added noVNC helper for interactive ChatGPT browser login.
